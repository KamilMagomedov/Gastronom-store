# 🛒 Gastronom — Online Grocery Store & Delivery App

A full-stack mobile application for grocery shopping and order delivery with an integrated admin backend.

## 🚀 Tech Stack

### Frontend (Mobile App)
* **Framework:** React Native (Expo)
* **Language:** TypeScript
* **State Management:** React Context API
* **Navigation:** Expo Router
* **UI/Styling:** Custom Styles, React Native Safe Area Context, Yandex Maps API Integration

### Backend
* **Framework:** Laravel (PHP)
* **Database:** MySQL
* **API Architecture:** RESTful API

---

## ✨ Features

* 📱 **Product Catalog:** Browse items by categories with real-time availability.
* 🛒 **Shopping Cart:** Add/remove items and update quantities seamlessly.
* 🗺️ **Interactive Maps:** Address selection and map integration powered by Yandex Maps API.
* 📅 **Flexible Delivery:** Select custom delivery dates and convenient time slots.
* 💳 **Multiple Payment Options:** Support for online card payments and cash on delivery.
* 📦 **Order Tracking:** Track order status and delivery updates in real-time.
