# 1C Integration v2 Documentation

## Overview
Новая версия интеграции с 1С для обработки товаров по алгоритму v2, который поддерживает:
- Обновление товаров в папке `storage/app/private/onec_v2/`
- Обработку свойств товаров
- Структурированное хранение изображений в папках `goods/ID_товара/`
- Многопоточный импорт из нескольких XML файлов

## API Endpoint
```
/integration/1c_v2/exchange
```

## Структура каталогов
```
storage/app/private/onec_v2/
├── goods/                 # Папки с XML файлами по ID групп
│   ├── 1/
│   │   ├── import___*.xml     # Основная информация о товарах
│   │   ├── offers___*.xml     # Пометки удаления
│   │   ├── prices___*.xml     # Цены и представление
│   │   └── rests___*.xml      # Остатки
│   ├── 2/
│   └── ...
├── properties/           # Свойства товаров
│   └── 1/
├── import___*.xml        # XML файлы импорта (основной)
└── *.rar                # Архивы с данными
```

## Процесс импорта

### 1. Аутентификация (checkauth)
```
GET /integration/1c_v2/exchange?type=catalog&mode=checkauth
```
Возвращает: `success\nSESSION_ID\nsession123_v2`

### 2. Инициализация (init)
```
GET /integration/1c_v2/exchange?type=catalog&mode=init
```
Возвращает: `zip=no\nfile_limit=10485760`

### 3. Загрузка файлов (file)
```
POST /integration/1c_v2/exchange?type=catalog&mode=file&filename=example.xml
```
Файлы сохраняются в `storage/app/private/onec_v2/`

### 4. Запуск импорта (import)
```
GET /integration/1c_v2/exchange?type=catalog&mode=import&filename=import___*.xml
```
Запускает `ImportFrom1Cv2Job`

## Алгоритм работы v2

### Обработка папок goods/
Система сканирует все папки в `goods/` и обрабатывает каждую:

1. **import___*.xml** - основная информация:
   - `<Товар>` - данные товаров (имя, артикул, описание)
   - `<Группа>` - категории с external_id
   - Извлекает изображения и свойства

2. **offers___*.xml** - пометки удаления:
   - `<Предложение>` - предложения
   - `<ПометкаУдаления>` - true/false для скрытия товара

3. **prices___*.xml** - цены:
   - `<Цена>` - информация о цене
   - `<Представление>` - "86,18 RUB за шт" для отображения на фронте
   - `<ЦенаЗаЕдиницу>` - числовое значение цены

4. **rests___*.xml** - остатки:
   - `<Остатки>` - информация об остатках на складах
   - Суммирует количество по всем складам

### Обработка категорий
- Автоматически создает категории по `external_id`
- Привязывает товары к категориям
- Поддерживает иерархическую структуру

### Обработка свойств
- Извлекает свойства из `<ЗначенияСвойств>`
- Автоматически создает атрибуты товаров
- Сохраняет значения в таблице `product_product_attribute`

### Обработка изображений
- Ищет изображения в `goods/ID_товара/`
- Поддерживает обратную совместимость с оригинальными путями
- Очищает старые изображения перед загрузкой новых

## Новые поля в моделях

### Product
- `price_representation` - текстовое представление цены для фронта

### Category  
- `external_id` - ID из 1С для синхронизации

## Логирование
Все операции логируются в канал `onec` с пометкой версии:
- Статус обработки папок
- Создание/обновление товаров
- Обработка категорий
- Ошибки импорта

## Отличия от v1
- **Многопоточный импорт** из нескольких XML файлов
- **Разделение данных** по разным файлам (import, offers, prices, rests)
- **Автоматическое создание категорий** с external_id
- **Представление цен** для отображения на фронте
- **Суммирование остатков** по всем складам
- **Улучшенная обработка изображений**
- **Отдельные Job и Service классы**
- **Маркировка логов** версией

## Использование
1. Настройте 1С на отправку данных на `/integration/1c_v2/exchange`
2. Убедитесь, что структура папок соответствует документации
3. Запустите миграции для добавления новых полей:
   ```bash
   php artisan migrate
   ```
4. Мониторьте логи в канале `onec` для отслеживания процесса импорта
